# MARS//PATH — Live-Verified Data Sources Registry

Date tested: `2026-11-13` (UTC `2026-11-13T23:00Z`)
Verification method: Direct HTTP requests via Node `fetch` from workspace runtime (`/app/applet`) inspecting status codes, headers, CORS, CRS/projection, and live payload schemas.

> **Verification Status Legend**
> - `VERIFIED_LIVE`: Endpoint tested live on 2026-11-13, returned HTTP 200 with valid expected payload/tiles. Adapters built against these exact schemas.
> - `VERIFIED_CACHED`: Live-verified and persisted to local SQLite windowed cache with explicit `retrievedAt` and `lastSynchronized`.
> - `DOCS_ONLY`: Documented externally, not queried live in runtime.
> - `UNAVAILABLE`: Tested and returned 403/404/500 or schema incompatibility; excluded from adapters and documented in `LIMITATIONS.md`.
